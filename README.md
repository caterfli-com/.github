## What it does

Your software never needed replacing. It needed an operator.

1. **Hand it a key.** One URL and one credential. The credential is encrypted before it is stored and decrypted only inside the connector, at the moment of a call.
2. **It reads the place.** Endpoints, tables, relationships and MCP tools are inspected and turned into described, schema-checked capabilities, each with a risk level attached.
3. **You review, then ask.** Caterfli drafts the agent — its purpose, its instructions, which capabilities it holds and which stop for a person. You approve it before anyone talks to it.

Nothing migrates. Nothing gets rebuilt. Disconnect it and your systems are exactly as they were.

## The model asks. It never acts.

The language model is treated as an untrusted planner. It proposes a call; the platform independently checks that:

- ✅ the tool exists and this agent may use it
- ✅ your workspace owns the connection
- ✅ the acting person holds the permission
- ✅ the arguments match the schema
- ✅ policy allows it — and anything destructive **pauses for a human**

An approval authorises exactly one call, with exactly the arguments that were reviewed.

```text
execution trace                                   paused
1. Message     Delete every customer inactive since 2023
2. Plan        delete_customer · 32 matches
3. Ownership   connection belongs to this workspace
4. Permission  customer.delete — granted
5. Schema      2 arguments validated
6. Policy      DELETE · CRITICAL — approval required
```
